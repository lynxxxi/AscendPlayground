# 三级任职材料缺口与提交前检查清单

| 优先级 | 材料或信息 | 当前状态 | 建议动作 |
|---|---|---|---|
| P0 | 个人基础信息、任职周期、部门和岗位 | 公开材料未提供 | 填写与申报系统一致的信息 |
| P0 | 内部性能与精度原始结果 | PR 仅有截图或结论 | 补测试环境、基线、目标值、实测值、日期和验证人 |
| P0 | 需求与设计评审记录 | 公开仓无法证明内部评审 | 补评审邮件、会议纪要或系统评审截图 |
| P0 | 版本商用或业务效果证明 | 公开仓只能证明合入 | 补版本发布、业务上线、项目验收或感谢材料 |
| P1 | 代码质量与 CI | 已有合入和部分流水线信息 | 补静态检查、覆盖率和 CI 成功截图 |
| P1 | 责任贡献统计周期 | 已有多个 PR | 确认起止日期后导出完整 PR 与代码量 |
| P1 | 指导他人或流程改进 | 当前公开证据较少 | 如有，补评审意见、协作分工或流程改进记录 |
| P2 | 专业回馈 | 三级标准不要求 | 无需为三级单独补充 |

需求分析与验证报告已依据公开合入事实补齐；内部阈值和测试环境仍须由申报人确认后才能作为正式定量结论。
