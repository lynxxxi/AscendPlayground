## 2. 背景与问题

多模态生成模型在多卡推理中常采用 UlyssesSP、RingSP 或融合并行。序列增长后，All-to-All/AllGather 等集合通信会暴露在关键路径上，单纯扩大并行规模可能因通信抵消计算收益。需求目标是统一序列并行注意力接口，并通过通信量化和多 Stream 流水减少不可掩盖通信。

## 3. 功能需求

1. 提供统一 `usp_attention` 接口，承载 Ulysses Head/Sequence 交换与 KV 聚合。
2. 支持 Q/K/V/Out 通信量化、反量化及 Scale 管理。
3. 支持 Head Chunk 流水，使通信与 FA 计算重叠。
4. 支持 Quant FA 量化结果复用，减少重复量化开销。
5. 覆盖单 Rank、分片、量化、重叠、复用和异常路径。
6. 输出中英文使用指南与模型级测试说明。

## 4. 非功能需求

- 性能：以不可掩盖通信占比为核心指标，目标场景缩小至 5% 以下。
- 精度：量化通信后模型生成精度满足项目门限。
- 可扩展性：覆盖 4 卡、8 卡，并允许后续扩展并行组合。
- 可靠性：校验进程组、分片维度、量化参数及 Stream/Event 顺序。
- 易用性：通过显式参数表达并行拓扑与量化策略，文档可直接指导接入。

## 6. 风险与约束

量化收益必须扣除量化/反量化和 Scale 通信开销；Chunk 太小会增加调度成本，太大则降低重叠空间；集合通信、NPU Stream 和 Event 的顺序错误可能导致死锁或读写竞争。模型结论依赖拓扑、序列长度和硬件环境。
