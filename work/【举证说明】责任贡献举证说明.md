## 三、核心责任结果

### 3.1 低比特量化注意力核心能力及产品化交付

围绕视频生成模型 Attention 的计算和显存瓶颈，完成 MXFP4 Quant Flash Attention、Metadata、多布局 Softmax 和部署端接入等关键能力，形成从需求、设计、框架接入、算子实现到 Golden/UT、模型端到端验证的交付闭环。MindIE 26.1.0 版本周报记录本人负责 Wan2.2 W4A4+FA MXFP4 量化需求，面向 A5 标卡 4 卡场景，版本目标为相对浮点性能提升 1.4 倍、挑战 1.8 倍；同时承担 MindIE-SD A5 在线/离线量化能力设计与开发。后续 RP3 周报记录 W4A4 与 FP8/MXFP4 稀疏量化框架和算子代码已完成开发，体现核心特性持续演进及版本承接。

对应合入成果包括 PR !313（QFA 与 Metadata 双算子）、PR !347（关键 Softmax 布局扩展）和 PR !365（部署端接入）。上述成果覆盖复杂算子方案、Host/AICore 实现、框架 API、异常校验及测试验证，支撑低比特 Attention 产品化集成。

### 3.2 USP 序列并行通信量化与通算重叠

针对多卡视频生成的通信瓶颈，完成统一序列并行 Attention、Q/K/V/Out 通信量化、Head Chunk 多 Stream 重叠及 Quant FA 结果复用。RP3 商发交付周报将本人列为该需求责任人，明确交付范围包括 USP+Ring 量化/非量化通信接口、4+4 与 8+8 并行、非对齐通信以及 Hunyuan 改造模型 1%—2% 性能收益，并记录代码已合入。

对应 PR !578 输出 904 行核心实现，PR !580 补齐测试和中英文使用指南，并形成 HunyuanVideo 4 卡、8 卡验证记录。该成果将通信压缩、集合通信和计算流水统一封装为可复用框架能力，改善多卡扩展效率和工程易用性。

### 3.3 客户交付与商业价值

OTT8 模型适配部感谢信明确列出本人为昇腾计算推理开发部贡献者。项目面向 Atlas 350 标卡多模态生成适配：通过可复用 NPU Fake 模型将客户一脚中台性能验收、整体性能跑通及生产环境适配周期缩短 50%；通信量化过程中，在三天内完成 6000+ 行代码开发。最终客户模型性能提升 43%，通信掩盖率达到 85%+，通信量化性能提升 17%，并一次性通过客户中台验收。该证据直接证明相关核心模块满足客户交付和商用验收要求，并将技术改进转化为客户可感知的性能和交付效率。

### 3.4 版本开发、质量看护与持续改进

除上述核心特性外，持续承担 Wan2.2 服务化推理精度、BF16 Quant Offset、QFA 构建、PEP517 版本覆盖、PyTorch Compile 兼容和量化 ATB 依赖等复杂问题定位，覆盖精度、构建、依赖、兼容及服务参数链路。两份蓝区代码看板分别记录 PR 创建 33/72 次、有效检视 135/168 次、检视总次数 745/596 次，并均标记为 Committer；由于统计范围不同，各组数据独立引用。上述成果体现对核心模块交付质量、社区准入和版本稳定性的持续看护。

## 四、论文研究与工程转化

### 4.1 RotateAttention

论文《RotateAttention: RoPE-Aware Rotation and Range Rectification for INT4 Quantized Attention in Video Generation》入选 ECCV 2026，作者列表包含 Jinxi Li。论文提出 RoPE-aware Rotation 和 Range-optimized P Quantization，在保证视频生成质量接近全精度基线的同时，最高实现 1.68 倍端到端加速和 2.2 倍算子级加速。ECCV 会务邮件发送至 Jinxi，进一步佐证作者参会身份。该成果与 MindIE-SD 的在线量化、量化 FlashAttention 和模型验证能力形成研究与工程协同。

### 4.2 MXAttention

论文《MXAttention: Data-Free Optimal Scaling and Pre-Normalization Quantization for MXFP4 Attention》（arXiv: 2607.24377）作者列表包含 Jinxi Li。论文针对 MXFP4 Attention 提出免数据最优缩放和预归一化量化方法；公开结果显示，在 Wan2.2 与 HunyuanVideo 上缩小至少 95% 的 OCP MXFP4 与 FP16 VBench Imaging Quality 差距，已报告指标相对 FP16 的绝对退化均小于 0.01。论文方法与 PR !313、!347、!365 的算子和部署链路相互印证，形成论文方案向产品代码转化的完整证据链。
