## 3. 推荐答辩主线

主案例一为 MXFP4 Quant Flash Attention：说明长序列注意力成本问题、双算子与多布局设计、部署端接入、Golden 和 Wan2.2 E2E 验证，突出算子—框架的多模块闭环。

主案例二为 USP 通信重叠与量化：说明集合通信暴露问题、Q/K/V/Out 量化、Head Chunk 流水、多 Stream/Event 可靠性和 4/8 卡验证。

在线量化、Compile/Custom Op 及疑难问题定位作为辅助案例，用于证明持续看护、重构和复杂问题解决能力。

## 4. 证据纪律

代码归属以 GitCode PR 页面及合入提交中的 Created-by、Commit-by、Co-authored-by 和 PR 编号为准；Merged-by 为平台机器人不影响归属。公开记录未提供的精度、性能数值不推测，引用内部原始报告时应补充环境、基线与统计口径。
