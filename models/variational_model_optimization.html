01 · Scope

“变分”是推断问题

目标是用可处理的分布 qφ(z|x) 逼近难以直接计算的后验 pθ(z|x)。VAE 是其中的摊销推断实现；本文也覆盖没有神经解码器的贝叶斯模型、离散潜变量与全局—局部层次模型。

log pθ(x) = ELBO(θ,φ;x) + KL[qφ(z|x) || pθ(z|x)]   ≥   ELBO = Eq[log pθ(x,z) − log qφ(z|x)]
统计效率多少步达到目标梯度方差、优化器、参数化与初始化决定收敛速度。
计算效率每一步多快小批量、粒子向量化、编译、融合、精度与并行决定墙钟时间。
近似质量q 是否够表达mean-field 便宜但可能低估相关性和不确定性。
下游效用结果是否可用预测、校准、生成或决策指标不能被 ELBO 单独替代。
02 · Cost anatomy

一轮推理迭代花在哪里

01 / DATA抽取小批量全局—局部模型还需按 N/B 缩放局部似然。
02 / GUIDE生成 q 参数摊销网络或每个样本的局部变分参数。
03 / SAMPLEK 个粒子连续重参数化；离散枚举或 score-function。
04 / LOG DENSITY模型与 guide计算 log p、log q、Jacobian 和解析 KL。
05 / UPDATE梯度与优化反向传播、自然梯度/Adam、全局参数同步。
Tstep ≈ Tinput + Tguide(B) + K × [Tmodel(B) + Tlog_prob] + Tbackward + Tsync
最常见误判：增加粒子 K 能降低部分 Monte Carlo 噪声，却近似线性增加计算；更紧的 IWAE bound 也不保证 inference network 的梯度信噪比同步改善。先画 ELBO、梯度方差、active units、吞吐与显存的联合曲线。

04 · Gradient estimators

先把梯度噪声降下来

CONTINUOUS

可重参数化变量

Normal、LogNormal 等优先使用 pathwise gradient。对约束变量在无约束空间参数化，再稳定地变换；scale 用 softplus 并设合理下界。

DISCRETE

离散潜变量

小状态空间优先精确枚举；否则用 Rao–Blackwell、RELAX/VIMCO 一类控制变量。Gumbel-Softmax 是有偏松弛，温度必须做消融。

MULTI-SAMPLE

多粒子目标

K>1 前先向量化；IWAE 的 guide 梯度可考虑 DReG。不要仅看 bound 更紧，还要看梯度 SNR、ESS 和单位时间提升。

可执行的方差诊断
固定同一 mini-batch 与参数快照 重复 R 次估计梯度 g₁…gᵣ 记录：mean(loss), std(loss), ||E[g]||, E[||g−E[g]||²] 比较：K=1/4/16；解析 KL on/off；vectorized on/off 离散变量：枚举 vs score-function + baseline 最终指标：达到同一验证目标的 wall-clock，而非单步 loss
05 · Inference paths

四条推理路线怎么选

CAVI / MESSAGE PASSING

有共轭结构：吃尽解析解

对每个变分因子使用闭式最优更新，或把共轭子图交给消息传递；采用残差优先、异步或分块调度。它通常比通用自动微分快，也更稳定，但要求模型结构可推导。

STOCHASTIC VI

大数据：局部快、全局稳

小批量估计全局自然梯度，局部变量并行优化；局部容差无需远高于全局更新精度。对流式数据使用递减步长或遗忘因子，并监控概念漂移。

AMORTIZED VI

高 QPS：一次前向给后验

用 inference network 直接预测 q 参数，把逐样本优化摊销到训练阶段。线上延迟最低；若 amortization gap 明显，采用 encoder 热启动 + 1–10 步局部精修，并设置按置信度触发的早停。

SEQUENTIAL / ONLINE

时序数据：复用上一时刻

过滤式 q(zt|x≤t) 追求低延迟，平滑式后验追求更高质量。缓存充分统计量或后验自然参数；分布突变时重置 warm-start，避免误差持续传递。

VAE 只是摊销推理的一种实现：若 KL 迅速趋零、active units 过少或 decoder 忽略 z，先诊断 posterior collapse，再考虑 KL warm-up、free bits 或改变 decoder/连接。不要把这种训练病态误判成“推理已经收敛”。
06 · Inference runtime

让每次后验求解更便宜

VECTORIZE

批量化所有独立轴

数据 plate、粒子 K、局部变量和必要时多重初始化都应成为张量维度。优先消除 Python for-loop，再做算子融合。

COMPILE

固定结构与 bucket

按 batch/序列长度分桶，编译稳定的 model+guide loss。把动态控制流留在图外，并分别计入首次编译和稳态时间。

PRECISION

分区低精度

神经网络 GEMM 用 BF16；概率密度、Jacobian、方差、logsumexp 和全局充分统计量保 FP32。低精度必须通过 ELBO parity 与后验校准。

在线服务：按难度路由

简单样本走 amortized 一次前向；低置信度样本追加局部精修或更多粒子；超时则返回保守后验。按 latent 维度、序列长度与 K 分桶合批，并分开报告编码、优化与后验采样延迟。

缓存与预计算

静态特征、稀疏设计矩阵、索引和不随 φ/θ 变化的项可缓存；流式场景缓存充分统计量与上一时刻 q。缓存键必须包含数据版本、模型 revision、预处理和变分族。

推理服务的延迟预算模板
T_total = T_preprocess + T_guide + N_local × T_ELBO + K × T_posterior_sample + T_post P50 路径：amortized guide → confidence gate → return P95 路径：warm-start → local refinement → convergence / timeout 优化顺序：减少 N_local → 向量化 K → batch/bucket → compile → mixed precision
07 · Decision route

按症状选第一步

01

ELBO 抖动、seed 差异大

固定 batch 重复测梯度方差 → 连续变量重参数化 → 解析 KL / Rao–Blackwell → 离散枚举或 baseline → 最后才增加粒子。

02

ELBO 高但预测或校准差

检查 likelihood 与数据标度 → posterior predictive check → mean-field 改低秩/结构化 → flow / mixture → 必要时用 MCMC 对小模型校准。

03

数据一大就跑不动

拆全局/局部变量 → 小批量 SVI 与正确 plate scaling → 摊销局部推断 → 稀疏计算与缓存 → 再做数据并行。

04

GPU 利用率低、单步很慢

profile model / guide / log_prob / input → 向量化粒子和 plate → 静态分桶与编译 → 混合精度 → 仅对实测热点写融合算子。

05

线上后验延迟超 SLO

先设 amortized 快路径 → 置信度门控局部精修 → warm-start 与自适应早停 → 粒子/精度按预算降级 → 后台异步做高质量平滑或校准。

08 · Validation

四道验收门

门槛必须报告常见失败
正确性解析小模型 / 枚举基准、shape、plate scaling、梯度检查小批量似然缩放错、事件维与批维混淆
收敛ELBO gap、局部迭代数、梯度方差、达到容差的 wall-clock固定迭代浪费简单样本；只报最终 loss
后验质量posterior predictive、校准、覆盖率、ESS、下游风险以 ELBO 单指标替代后验效用
推理效率冷/热 P50/P95 延迟、QPS、K/N_local、峰值显存、超时率隐藏编译与排队；把显存下降写成加速
推荐基准命名：model@revision / variational-family / estimator / K / batch / dtype / device×count / compile / seed×N / quality-gate。所有“×倍加速”只与同数据、同后验族或明确标注的质量等价基线比较。
09 · Primary sources

来源与边界

  1. Auto-Encoding Variational Bayes：重参数化 ELBO 与摊销推断。
  2. Stochastic Variational Inference：大数据小批量 SVI、全局—局部结构与自然梯度。
  3. Black Box Variational Inference：score-function 梯度与方差缩减。
  4. Variational Inference with Normalizing Flows：以可逆变换增强近似后验。
  5. Improved Variational Inference with Inverse Autoregressive Flow：高维 flow 后验与 free-bits 训练思路。
  6. Doubly Reparameterized Gradient Estimators：多样本目标的低方差梯度。
  7. Understanding Stochastic Natural Gradient VI：自然梯度在共轭与非共轭设置下的收敛边界。
  8. Pyro SVI / ELBO 官方文档：粒子向量化、离散枚举、Rao–Blackwellization 与 JIT 接口。
  9. Pyro Normalizing Flow Guide：flow guide、向量化粒子与梯度裁剪的实现示例。

边界：本文主线是通用变分推理算法与推理运行时，不包含扩散模型或所谓“变分扩散”。VAE 仅作为摊销推理案例；自然梯度、IWAE、flow、局部精修和低精度都必须在目标后验上做质量—延迟消融。
