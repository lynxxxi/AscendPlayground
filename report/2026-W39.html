NEW2026-09-22GravityOCR：扩散草稿加自回归验证的文档 OCR 加速
自回归 OCR 视觉语言模型每个输出 token 需要一次串行解码，限制了推理速度，而 OCR 输出强依赖于输入图像，适合扩散式并行生成；但一步扩散同时预测的多个 token 彼此未知，直接提交会引入错误。GravityOCR 是参数共享的自回归块扩散模型，联合训练并行草稿与因果 AR 验证，先验证再提交即可每轮提交多个 token 且不需要独立草稿网络，因果 AR 路径还支持带 OCR 序列与结构奖励的 GRPO；在 OmniDocBench v1.6 上 AR 路径 GRPO 把 Overall 从 94.92 提升到 95.16，并在 SGLang 服务部署中验证。

NEW2026-09-22Tessera：把逻辑掩码与 GPU 执行解耦的动态块稀疏注意力运行时
针对视频扩散 Transformer 迭代去噪中注意力开销过大的问题，Tessera 在运行时把逻辑注意力块映射为适配不同掩码形状与 GPU 架构的物理 tile，并通过分组调度复用数据、把数据搬运与计算重叠。执行计划由离线 profiling 得到的查找表选出，以避免运行时 kernel 特化带来的准备开销。

NEW2026-09-22Flash-dLLM：面向扩散 LLM 的 IO 感知 KV 缓存与并行解码
扩散 LLM 通过非自回归生成提供了一条替代自回归的路线，但缺少有效的 KV 缓存与可扩展的并行解码机制，已有加速方法又通常把两者分开研究，忽略了缓存复用与并行 token 验证联合使用时出现的 I/O 瓶颈。Flash-dLLM 先把 GPU 显存 I/O 认定为开启 KV 缓存后的主要瓶颈，用 I/O 感知的融合 KV cache kernel 减少冗余搬运，再据此提出 KV 缓存驱动的 draft-and-verify 解码策略，让模型自身兼任草稿器与验证器而无需辅助模型，属于免训练的 dLLM 推理加速。

NEW2026-09-21RGSQ：面向大型视觉语言模型的黎曼几何敏感量化
多数训练后量化方法是为单模态 LLM 设计的，把量化误差当作欧氏假设下的各向同性扰动，对 VLM 中最敏感的方向指引不足，直接套用或仅做模态特定缩放会导致位宽分布不均与低位设置下性能不稳。RGSQ 在统一的 Fisher-Riemannian 度量下把量化写成重构问题，用按模态划分的经验 Fisher 因子构造模态感知的 Kronecker 结构度量来定位敏感方向，再以几何对齐旋转和白化变换把低位扰动导向损失不敏感轴，属于 VLM 的低位量化方法。

NEW2026-09-21无人机 VLM 部署画像：端侧、云端与切分计算对比
无人机等边缘设备上 VLM 的端侧推理受算力、显存与能耗限制，云端推理则带来通信延迟、带宽开销与网络依赖，切分计算是折中方案但三者取舍缺乏系统测量。本文以 SmolVLM-256M 为代表，在不同图像分辨率与网络条件下量化三种部署范式的推理延迟、资源利用、通信开销与能耗，结论是没有一种策略在所有条件下最优，属于轻量 VLM 边缘部署的选型依据。
arXiv
NEW2026-09-21SPHQuant：面向 VLM 的极低位仅权重量化
原生多模态 VLM 的语言骨干显存占用大且自回归解码受显存带宽限制，边缘部署需要极低位权重量化，但 2-3bit 下免旋转方法受离群值影响、基于旋转的方法又以额外运行时开销换取精度。SPHQuant 采用免旋转的球面权重表示，把每个 8D 权重向量分解为坐标符号、半径与正单位方向，将离群幅度隔离进半径并为其分配额外精度，同时使用紧凑的正方向码本并按角度参数微调码本项，属于 VLM 仅权重量化方向的工作。
arXiv
NEW2026-09-21VPRune：面向 LLM 之前的免训练视觉 Token 剪枝
针对激进视觉 token 压缩导致 LVLM 性能明显下降的问题，作者归因为文本引导的选择偏置、被丢弃 token 的信息损失以及序列压缩带来的位置失真三点，并提出在进入 LLM 之前完成的免训练剪枝框架，由仅视觉的多样性选择、相似度引导的 token 回收与位置保持复原组成。在 FastVLM-1.5B 的多项视觉语言基准以及边缘设备上，它在激进压缩下取得更好的精度与压缩折中并降低端到端延迟。

NEW2026-09-21H-Spec：无需草稿侧 KV Cache 的并行投机解码
块扩散草稿器能并行预测多个 token，但现有做法要为每个输入位置把目标隐藏状态投影进独立的草稿侧 KV cache，带来随并发增长的每请求显存与 KV 写入开销，而直接原地复用目标 KV 又难以在整块内维持草稿质量。H-Spec 采用混合目标上下文注入，仅在最后一个输入位置补充目标隐藏状态，其余直接复用目标 KV；草稿器融合 Mamba 与注意力模块分别消费两类上下文，并借 Mamba 并行扫描保持块并行草稿，属于投机解码的显存与延迟优化。

NEW2026-09-19语义-几何解耦路由的免训练块稀疏注意力
长上下文推理中稠密注意力随序列长度二次增长，而块稀疏注意力依赖的免训练块路由仍不准确：现有路由器常在 RoPE 之后的表示上池化，把语义聚合与 RoPE 引入的几何纠缠在一起，并通过高频相位抵消削弱局部位置线索。该方法把语义聚合移到 RoPE 之前，并用离线结构先验与相对块距离重建几何偏置，得到显式闭式的块路由分数，无需 token 级搜索或后校准；在文本与视频长上下文任务上接近全注意力精度，属于长序列注意力的推理加速。

NEW2026-09-17PixelFlow：面向分布式 DiT 服务的 Token 级负载管理
针对请求级批处理难以控制批大小、批过小无法打满 GPU 而批过大又违反延迟 SLO 的问题，PixelFlow 改用图像 token 作为划分与批处理负载的粒度，让每张 GPU 在延迟约束下多承担一部分工作。通过把这些负载分片分散到各 GPU，系统容纳更多并发请求并降低排队延迟，属于 DiT 在线图像生成的服务调度与利用率优化。

NEW2026-09-17DeepSeek-V4.1-Flash：把 KV Cache 压缩推到极限

NEW2026-09-17MiX：面向端到端低位 VLM 加速的微缩放反转量化格式
边缘设备上 VLM 受显存带宽限制需要亚 8bit 量化，但多模态 token 之间极大的动态范围差会让共享指数被单个离群值劫持，出现微缩放崩塌并破坏注意力图。MiX 把微缩放范式反转：不再用共享指数统管多个尾数，而是让多个私有逐元素指数共用一个共享尾数，并以自适应双格式推理框架通过代数分解让算子映射为移位器，属于低位 VLM 的端到端加速方案。
