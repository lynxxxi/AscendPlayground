# 生成领域前沿研究报告：页面设计说明

## 目标与受众

页面面向研究工程师、技术负责人和平台规划者，回答三个问题：当前最关键的模型与框架是什么、哪些优化技术能够迁移到工程实践、未来 6—18 个月应该优先验证什么。它不是论文罗列页，而是一张从图像、音视频与 3D 资产生成通向具身世界模型和实时交互系统的技术地图。

## 信息架构

采用“结论先行—地图定位—框架分层—证据展开—工程决策”的阅读顺序。首屏给出五条核心判断与技术路线概览；随后依次呈现技术版图、框架生态、代表模型雷达、具身世界模型、长视频与流式生成、优化技术栈、评测与风险、Ascend 侧验证路线和来源。框架章节区分数据与硬件、VLA 策略、世界模型转换、视频底座和训练服务五层，并增加 vLLM-Omni、SGLang-Omni/Diffusion、LightX2V、FastVideo、TurboDiffusion、CacheDiT 与 xDiT 的系统选择矩阵。模型条目按开放可复现、开放权重/部分开放、闭源预览分层；I2V 排名作为带日期和口径的独立快照呈现，所有性能数字保留硬件和来源语境。

## 视觉方向

选择“深色研究雷达 / 编辑部技术档案”风格：煤黑背景、荧光黄绿作为信号色、冷青用于世界模型、橙红用于风险。使用网格、刻度、编号和大字号窄体标题营造实验室仪表盘感，同时用衬线中文正文保证长篇阅读。页面不依赖远程图片或框架，单文件离线可用。

## 交互与实现

单个 `index.html` 内联 CSS 与 JavaScript。包含滚动进度、粘性目录、模型类型筛选、全文关键词筛选、可展开技术卡、来源跳转和回到顶部。移动端折叠为单列布局；尊重 `prefers-reduced-motion`；按钮提供焦点态；表格在窄屏横向滚动。数据以 HTML 为主，避免 JavaScript 失效时丢失正文。

## 验证

验证 HTML 基本结构、链接协议、脚本语法、响应式断点与无障碍标签；在本地浏览器截图检查首屏、模型矩阵和移动端布局。研究内容以 2026-08-11 为检索截止日，优先引用论文、项目主页、官方仓库和研究机构页面，并标注尚未独立复现的指标。
