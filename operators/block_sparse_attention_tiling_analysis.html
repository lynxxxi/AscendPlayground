3. 稀疏分块（Block Sparse）策略

BlockSparseAttention 的核心思想是：将 Q 和 KV 序列按 blockShapeX 和 blockShapeY 切成块， 仅对 blockSparseMask 标记为 1 的 (Q_block, KV_block) 对计算注意力。

图3：Block Sparse 分块与 Mask 过滤示意
关键约束： blockShapeY 必须是 128 的倍数；blockShapeX 默认 128。 BlockSparseMask 的 shape 为 [B, N, xBlockNum, yBlockNum]， 其中 xBlockNum = ceil(maxQSeqlen / blockShapeX)， yBlockNum = ceil(maxKvSeqlen / blockShapeY)。

设计要点：
  • 910 采用 粗粒度任务切分（Q_block级别），950 采用 细粒度BaseTile切分（qBaseTile级别），950粒度更细、并行度更高
  • 950 的 L1 分块策略根据 embeddingSize (D=128/256) 自适应调整 M/N/K 切分和缓冲数量，最大化 L1 利用率
  • P 矩阵在 950 上使用 三缓冲（适配 prelaunch=2 的流水线），避免基块间流水阻塞
  • Mask2Idx 预处理阶段将 uint8 稀疏掩码转为 int32 索引，后续 Matmul 只需按索引加载活跃 KV 块
  • 950 Workspace 更精简——中间矩阵通过 L1/UB 核内流转，仅保留稀疏索引空间
